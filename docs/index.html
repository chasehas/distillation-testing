The Distillation Premium: An Empirical Benchmark

Controlled evaluation of knowledge distillation from GPT-4 to small open models

Section 1

The Distillation Premium

I fine-tuned Qwen2.5-0.5B on 150 math reasoning problems using LoRA, holding compute constant across conditions. The only variable was the source of training solutions: human crowdworkers (GSM8K reference answers) vs. GPT-4 chain-of-thought outputs. On a held-out test set of 100 GSM8K problems, the GPT-4-trained model scored 46% vs. 32% for the human-trained model — a 14 percentage point gap that held across training set sizes from 150 to 1,000 samples. Training on human-written solutions provided negligible improvement over the untrained baseline, meaning further performance gains effectively require distillation from a stronger model.

Key Findings

  • 1. The distillation premium is consistent across data budgets — GPT-4 trained models hold steady at ~46% accuracy from N=150 to N=1000, while human-trained models hover near or below the 29% untrained baseline.
  • 2. Reasoning traces are the mechanism — training on GPT-4's direct answers without chain-of-thought collapses accuracy to 3–14%, worse than the untrained model. The same answers with step-by-step reasoning reach 46%.
  • 3. The premium compresses with model scale — a 1.5B student already scores 62% zero-shot, leaving only +4 percentage points of distillation uplift vs. +14 on the 0.5B model.
Section 3

Extensions & Future Work

  • Generalization across model scale: A preliminary run on Qwen2.5-1.5B showed the distillation premium compresses to +4 percentage points as the student's zero-shot capability increases (62% base). This suggests distillation is most valuable for models that haven't yet saturated on the target task — but even capable models benefit, and training them on weak human data can actively hurt performance (−8 percentage points on the 1.5B model).
  • Generalization across domains: I ran the same experimental design across instruction following (UltraFeedback), code generation (MBPP), structured JSON extraction, and multiple-choice science reasoning (ARC-Challenge). Math reasoning showed the clearest premium. Code generation showed none at either model scale, likely because sub-1B models lack the capacity for executable Python regardless of training data quality.
  • Scaling the teacher: All distillation used GPT-4 as the frontier source. Comparing distillation from different teacher quality tiers (e.g., GPT-3.5 vs. GPT-4 vs. o1) would isolate how much of the premium comes from teacher capability vs. the structured reasoning format itself.
  • Compute-matched baselines: The current comparison holds training compute constant but uses pre-generated teacher outputs. A stricter comparison would account for the inference cost of generating those outputs.
